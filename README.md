# Cybersecurity & Digital Forensics Portfolio

This repository showcases practical cybersecurity and digital forensics work completed in controlled lab environments.

The projects demonstrate hands-on experience with forensic investigation, vulnerability assessment, network forensics, evidence handling, password recovery, and security tooling.

> All systems, credentials, evidence, network traffic, and malware samples shown in this repository were used in authorized educational or simulated lab environments. Sensitive academic and identifying information has been redacted.

## Projects

**Key skills demonstrated:**

- Hash verification
