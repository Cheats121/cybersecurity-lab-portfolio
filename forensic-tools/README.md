# Forensic Tools Lab

## Overview

This project involved building a virtual digital forensics lab and evaluating several forensic tools across Windows and Linux environments.

The goal was to understand how different tools support digital investigations and to evaluate their strengths, limitations, and practical use cases.

## Lab Environment

The lab consisted of two virtual machines:

- Windows
- Ubuntu Linux

The virtual machines were configured using VMware Workstation.

## Tools Evaluated

### Autopsy

Autopsy was used for disk and file system analysis.

Features explored included:

- Directory navigation
- File extraction
- Metadata analysis
- Timeline analysis
- Deleted and hidden file investigation
- Report generation

### NetworkMiner

NetworkMiner was used to analyze packet capture data.

Features explored included:

- Host identification
- Network session analysis
- File reconstruction
- File extraction
- Credential analysis
- Operating system identification

### Volatility

Volatility was evaluated as a memory forensics framework.

Its capabilities include:

- Process analysis
- Network connection analysis
- Registry artifact extraction
- File handle analysis
- Memory-resident artifact investigation

### OSForensics

OSForensics was evaluated for its capabilities in:

- File searching and indexing
- Hash matching
- Disk imaging
- Memory analysis
- Email analysis
- Binary data investigation

## Network Forensics Analysis

NetworkMiner was used to analyze PCAP data and inspect network hosts.

The investigation included:

- IP address identification
- Host and operating system analysis
- Network connection analysis
- File reconstruction
- Authentication and credential information

## Autopsy Analysis

Autopsy was used to investigate disk image data.

The project explored:

- Directory structure
- File metadata
- Extracted files
- Timeline analysis
- Forensic report generation

## Skills Demonstrated

- Digital forensics lab setup
- Network forensic analysis
- PCAP analysis
- Host identification
- Credential artifact analysis
- File extraction
- File system analysis
- Metadata analysis
- Timeline investigation
- Memory forensics concepts
- Forensic tool evaluation

## Key Takeaway

Different forensic tools are designed for different investigative tasks.

NetworkMiner was particularly useful for extracting and organizing information from network traffic, while Autopsy provided a structured interface for examining disk images and file system evidence.

Using multiple forensic tools provides a more complete view during an investigation.
